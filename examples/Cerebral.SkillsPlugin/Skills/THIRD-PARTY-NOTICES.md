Adaptations preserve the useful engineering disciplines while following Cerebral's owner instructions, Main/coordinator/Worker roles, existing tool grants, typed execution, scope and verification holds. No upstream scripts, hooks, installer commands, marketplace registration, Claude configuration, unattended external publication or network updater is included. Automatic multi-agent requirements and blanket mandatory execution/approval rules were replaced by the current task's actual authority. Upstream setup/router, issue-tracker orchestration, provisioning wizards and unrelated/in-progress/miscellaneous skills were excluded from this base.

This is shipped passive content. It is indexed locally and new catalog installations remain disabled/unassigned until the owner enables them for an existing scope. Updates to upstream are not fetched automatically. Review the actual instruction text before export; the exporter excludes application secrets/history/permission records, but cannot infer whether an author has written a secret into a document.
