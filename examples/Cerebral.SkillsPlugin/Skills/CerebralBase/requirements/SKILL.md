# Clarify requirements

Read the current request and relevant project evidence before asking questions. Separate facts you can inspect from choices that belong to the owner.

Map consequential decisions and their dependencies. Resolve available facts through the currently permitted tools. Ask a short round of independent questions only when the answer changes functionality, authority, security, data ownership, deployment, or scope. Offer a recommendation and its consequence. Continue independent authorized work while an optional answer is pending.

Use the owner's existing decisions. Do not restart an interview, demand confirmation for routine reversible choices, or treat silence as required approval. Record necessary assumptions and acceptance criteria in the existing task context.

For Cerebral, distinguish the human owner, Main, the coordinator, and Worker execution. A skill is passive guidance; it does not grant a new tool, file root, command, network connection, or permission. Delegation and additional agents require the authority already established for the task.

Finish with a concrete statement of the requested behavior, the evidence that will establish it, and any decision that remains genuinely necessary. Follow through within the authorized scope.
